это игра про сбор яблок в саду и искания червика 
в ней есть оптимизация настройки и т.д
запуск выполняется только после скачивания пайтона после скачивания откройте файл run.ry и у вас появится командная строка в ней будет локальный код сылки и сразу после неё откроется игра 
чтобы запустить для телефона нужно из командной строки взять вторую сылку типо local://8000 и просто через пк передать сылку в телефон и открыть на телефоне игра попросит перевернуть телефон
